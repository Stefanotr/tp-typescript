# TP TypeScript — Introduction au Fonctionnel

Ce projet contient un TP d’introduction à la programmation fonctionnelle en TypeScript.  
On y retrouve les notions suivantes :

- fonctions pures et impures  
- immutabilité  
- fonctions d’ordre supérieur  
- `map`, `filter` et `reduce`  
- `find`, `some`, `every` et `flatMap`  
- tri et manipulation de listes  
- cas pratique complet sur des données utilisateurs  

## Fichiers

- `tp-fonctionnel.ts` : code principal du TP  
- `tsconfig.json` : configuration TypeScript  
- `package.json` : dépendances et scripts  

## Exécution

Installer les dépendances :

```bash
npm install
````

Lancer le fichier TypeScript avec ts-node :

```bash
npx ts-node tp-fonctionnel.ts
```
